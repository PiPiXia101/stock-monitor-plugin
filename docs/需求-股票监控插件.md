# 需求：DSH 股票监控插件

## 一、需求背景与目标

用户希望在 DSH 网页界面中增加一个"股票监控"插件：根据股票编号（A 股）自动搜索相关新闻和公告，调用大模型生成分析结果，并能在面板中针对股票提问对话。

- 用户原话：*"我想做一个炒股的监控插件接入到 dsh 里面，可以根据我的股票编号去搜索相关新闻，然后给分析结果，最好再进行对话之类的"*
- 目标：一个可挂在 DSH web 侧边栏的独立 UI 面板插件，完成"自选股 → 新闻 → AI 分析 → 对话"闭环。

## 三、技术核实结论（来源：实测/读代码）

1. 东方财富免费接口可用（2026-08-16 实测）：
   - 个股公告接口 `np-anotice-stock.eastmoney.com/api/security/ann`：按 `stock_list=600519` 返回公告标题/日期 ✅
   - 新闻搜索接口 `search-api-web.eastmoney.com/search/jsonp`：按关键词返回新闻标题/摘要/媒体/链接/日期 ✅
2. DSH 插件机制（读 `~/.dsh/profiles/` 下已装插件包源码确认）：
   - 插件包在 package.json 声明 `dsh.client`（inject 依赖 + client 入口），浏览器端通过 `window.__ModuleLoader__.load()` 注册 UI
   - 服务端为 cordis 插件（`apply()`），客户端经 `@deepseek-ai/dsh-api-remotes` 的 `ctx.remote` 调用后端能力
   - profile 挂载：`~/.dsh/profiles/web/` 的 bundle 列表 + `cordis.patch.yml`

## 四、需求确认书

### 需求理解（大白话）

在 DSH 网页里加一个"股票监控"页面。你在页面上维护一个自选股列表（输入 A 股代码添加），插件每隔一段时间自动刷新，每只股票抓取最新的新闻和公告；发现新新闻时，在面板上高亮提醒。你可以让 AI（DeepSeek）对每只股票最近的新闻做分析，给出偏利好/偏利空/中性的结论和要点解读。页面上还能输入问题提问，AI 会结合这只股票抓到的新闻来回答。

### 范围边界

**做：**
- A 股自选股列表管理（添加/删除，代码 6 位数字校验）
- 定时自动刷新（默认每 5 分钟一次，可配置），拉取每只股票的公告 + 新闻
- 新新闻高亮提醒（面板内显示"新"标记/置顶）
- 用 DeepSeek API 对每只股票最新新闻生成分析（结论 + 要点）
- 面板内提问，AI 结合当前股票新闻回答

**不做：**
- 不做行情数据（股价、K 线、分时）
- 不做交易/下单
- 不做港股/美股
- 不做外部渠道推送（微信/钉钉/桌面通知）
- 不做技术指标/量化分析
- 不修改 DSH 核心代码（只新增独立插件包 + 挂载配置）

## 五、第一性原理审视（初步）

对用户原始想法的审视（在确认书确认后继续完善）：

1. **"监控"的真实动机待验证**：用户选择"定时自动刷新 + 新新闻提醒"，但未说明盯盘场景（盘中盯消息？盘后看公告？）。若为盘中，刷新频率 5 分钟是否够用、是否需要盘中重大新闻即时提醒，需后续确认。
2. **新闻源覆盖度有限**：东方财富接口覆盖公告 + 财经媒体新闻，但**不覆盖**雪球/股吧等社区讨论。若用户在意舆情情绪，社区数据是重要来源，但爬取成本高、易封 IP。当前方案先用东财数据，属合理取舍，需用户知悉。
3. **AI 分析的质量边界**：DeepSeek 分析基于新闻文本，无法预测股价、无法覆盖未披露信息。需在面板中明确标注"AI 分析仅供参考，不构成投资建议"，避免误导。
4. **接口稳定性风险**：东方财富免费接口无 SLA，可能限流/改版。插件需做好异常兜底（提示而非崩溃），并预留数据源抽象层。
5. **定时任务生命周期**：插件挂载在 DSH 进程内，DSH 关闭时监控暂停；若需 7×24 监控需独立进程。当前接受"随 DSH 运行"，需用户知悉。

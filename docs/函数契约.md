# 正式代码函数契约（测试数据构造依据）

本文件定义股票监控插件的核心业务函数契约。测试代码与测试数据全部按此契约构造；
正式代码实现时必须与契约一致（逻辑复用自测试通过的代码）。

## 数据结构

### 1. 股票（watchlist item）
```json
{
  "code": "600519",          // 6 位数字 A 股代码
  "name": "贵州茅台",         // 股票名称（抓取时填充，可为空）
  "addedAt": "2026-08-16T10:00:00+08:00"
}
```

### 2. 新闻条目（normalized news item，东财响应解析后的统一结构）
```json
{
  "id": "202608153842417957",   // 唯一 ID（东财 news code / art_code），用于去重
  "title": "茅台半年报：营收微增净利首降",
  "source": "21世纪经济报道",    // 来源媒体
  "time": "2026-08-15 15:58:10",
  "url": "http://finance.eastmoney.com/a/202608153842417957.html",
  "content": "摘要文本（可为空）",
  "type": "news" | "announcement"   // 新闻 or 公告
}
```

### 3. AI 分析结果
```json
{
  "conclusion": "偏利好" | "偏利空" | "中性",
  "points": ["要点1", "要点2"],
  "raw": "DeepSeek 原始返回文本"
}
```

### 4. 定时刷新产出
```json
{
  "code": "600519",
  "refreshedAt": "2026-08-16T10:05:00+08:00",
  "items": [ /* 全部新闻（新→旧） */ ],
  "newIds": ["...", "..."],   // 本次刷新新增的新闻 ID（用于高亮）
  "error": null               // 失败时为错误描述字符串
}
```

## 函数签名

| 函数 | 签名 | 说明 |
|------|------|------|
| `validateStockCode(code)` | `(string) => {ok: boolean, reason?: string}` | A 股代码校验：必须为 6 位数字；非 6 位数字返回 `{ok:false, reason}` |
| `parseAnnouncements(raw)` | `(东财公告接口响应JSON) => newsItem[]` | 解析公告：取 `data.list[]`，字段缺失的条目跳过 |
| `parseNews(raw)` | `(东财新闻搜索接口响应JSON) => newsItem[]` | 解析新闻：取 `result.cmsArticleWebOld[]`，字段缺失的条目跳过 |
| `findNewNews(prevItems, currItems)` | `(newsItem[], newsItem[]) => string[]` | 按 `id` 去重，返回 `curr` 中 `prev` 没有的 id 列表（新→旧保持顺序） |
| `buildAnalysisPrompt(code, name, items)` | `(string, string, newsItem[]) => string` | 拼接发给 DeepSeek 的 prompt：含代码、名称、新闻标题+摘要清单 |
| `parseAnalysis(rawText)` | `(string) => analysisResult` | 解析 DeepSeek 返回文本：识别「结论」与「要点」；无法识别时结论=中性、要点=[原文] |
| `buildQAContext(code, name, items, analysis)` | `(...) => string` | 拼接提问上下文：股票信息 + 新闻清单 + 分析结论 |
| `watchlistStore` | add/remove/list 三方法 | 自选股增删查（持久化到配置文件） |

## 边界与异常约定

- `validateStockCode`：`""`、`"abc"`、`"12345"`（5位）、`"6005190"`（7位）、`"600 519"`（含空格）全部为不合法
- `parseAnnouncements/parseNews`：响应结构不符（无 `data`/`data.list` 非数组等）返回 `[]` 且不抛异常；单条缺字段（无 `title`/无 `url`）跳过该条
- `findNewNews`：`prev` 为空 → 全部为新增；`curr` 为空 → 无新增；两条 id 相同但内容不同 → 不算新增
- `parseAnalysis`：DeepSeek 返回空串/纯乱码/不含结论词 → 结论=中性，points=[raw 截断 200 字]
- `watchlistStore.add`：重复代码 → 返回错误不重复添加；非法代码 → 拒绝
